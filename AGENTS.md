# Shared skills

Edit shared engineering guidance here. Dotfiles and Dev Kit consume pinned copies; do not introduce a second authored copy in either consumer.

Use normal Markdown paragraphs without manual line wrapping. Preserve each skill's invocation policy, source attribution, and licenses. Keep essential rules in the entrypoint and conditional detail in references.

Run `uv run --with pyyaml python scripts/validate.py` after changing skills or their references. Keep validation proportional to the change; prose changes do not require model evals or new verification frameworks.
